# Design

Mission control for a job search. Near-black field, one acid-lime accent, one tide-pool secondary. Instrument Serif for display, Instrument Sans for UI. Glass is only the floating command palette and the hero instrument, with a 1px light edge and a grain overlay. No gradient type, no blob fields, no icon-card grids.

Spacing is an 8px grid. The signed-in app is a list and a kanban. The public page earns one motion: the application orbit.
