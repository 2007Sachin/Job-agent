# Roast fixes

Verdict was go, on the condition that the product is the job loop.

| Roast point | Fix |
| --- | --- |
| First screen was an empty helper chat | Home is Find a job, recent saves, follow-ups due, and resumes. Each step is one link. |
| Helper desk was the product | Sidebar is Home, Find jobs, Saved, Applications, Resumes, Follow-ups, Plans, Settings. One Helper link sits on a job. |
| Desk tools were always on | Team map, published items, automations, group chats, the profile drawer, the screen panel, and the model picker are behind Advanced in Settings. Off by default. |
| Raw env names | The UI says Free AI model and Your AI key. `LLM_BASE_URL` and `env:LLM_MODEL` are not shown. |
| Fake connected state | Apps say Not connected, Coming soon, or Opens in your tab. Gmail has a real connect link. There is no Mark connected button. |
| Plans did not sell the loop | Free is 5 resumes a month. Plus is unlimited resumes, cover letters, and email follow-ups, marked Coming soon, with a waitlist. |
| Mobile header and dev badge | The helper chip truncates. `devIndicators` is off. |

## Round 1

| Point | Fix |
| --- | --- |
| Home search did not run | Find jobs runs one search when the URL has a role or a location, then shows results or an empty state for that query. |
| Resume box looked finished | Empty resume says to press Make my resume and that the draft uses only Settings. A missing key or a server error sits by the box. You can paste. No invented biography. |
| Score was a bare number | The job page says Fit note: N out of 100, lists the reasons, and says it is not an ATS score. |
| Rejected was off the board | Applications wrap on a 2 / 3 / 5 column grid. All five stages stay. |
| Follow-ups were dates only | Rows link to the job, with Mark done and Open job. Dates look like 1 Nov 2026 in Asia/Calcutta and say Overdue or Due today. No email is sent. |
| Saves looked like catalog finds | Catalog displays as Saved by you. Demo sign-in does not fill an email or a sample name. The extension test save says it is not a found posting. |
| Plus claimed cover letters | Cover letters stay on Free. Plus does not list them. No checkout and no price. The waitlist stays. |
| Extension had no download | Settings links to job-agent-extension.zip and the Chrome load-unpacked steps for the unzipped folder. Terms stay. Nothing is marked connected. |
| Ask Helper opened the desk | With Advanced off, Ask about this job is one thread about that job. No desk, drawer, model picker, or new helper. |
| Home did not say who applies | Under the lede: you still apply on the company site. Job-agent does not sign in to job boards or submit applications. |
